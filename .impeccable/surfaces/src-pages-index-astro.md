# Surface: home, about, 404 (RepoWeekly)

Mode: Read. The visitor understands what is trending this week and decides which repos to open.

Audience, job, proof: developers and students scanning ten entries once a week. Proof is the data itself: gained stars, daily gains, signals. Nothing invented. Fixture owners start with `fx-`.

Unattended run: the user asked to proceed without an interview or decision page. PRODUCT.md is inferred and labelled. The assigned direction was built as dealt.

Weighed and declined: hand-drawn zine, cutting bench, sticker case, alphabet storm. Competitive, not built: star atlas (kept its fixed magnitude ramp as a discipline). Raise from the provenance ribbon: uncertainty is marked inside the figures themselves (bootstrap week, spike), never in a footnote.

## Direction contract

THESIS: The week as a pocket tide table. A weekly ranking is a table of daily values, so the page reads like a nautical almanac page, not a card feed. Refuses the card-grid trending list and the cream-paper-and-serif editorial look.

OWN-WORLD: Admiralty-chart palette. Light: pale shallow-water blue ground, deep chart-ink navy text, chart magenta as the single mark colour for spikes, flags and focus. Dark: night chart, deep navy ground, chalk ink, softened magenta. One variable grotesk (Archivo, width axis): condensed caps for the masthead and rank numerals, normal width for reading text, tabular figures everywhere data appears. Hairline rules, no shadows, no rounded cards, thin ruled rows like a printed table.

STORY: The visitor learns which ten repos gained the most stars this week, reads in two sentences what each one is, sees honest signals beside the hype, and opens the repo, the archive or the feed. Success is an entry understood without leaving the page.

FIRST VIEWPORT: Masthead band at the top: RepoWeekly in condensed caps at left, nav (This week, Gems, About, Feed) at right. Under it one plain sentence stating the week and range ("Week 45, 2 to 8 November 2026. Ten repositories ranked by stars gained.") then the first entries. Each entry is a ruled row: huge condensed rank numeral in a left column, the name and plain description in the reading column (about 66ch), and the seven-day tide strip (Mon to Sun figures with a bar under each) plus a signals table in a right column on wide screens; stacked on phones with the rank inline. No hero, no kicker, no metric tiles.

FORM: Pocket nautical almanac and tide table, position 3 of 7 grounded candidates (league table, field guide, almanac, timetable, seed catalogue, card catalogue, type specimen). seed:f74fcaa2a78e867b
